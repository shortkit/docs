| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `apiKey` | `String` | **required** | Your publishable API key. Starts with `pk_live_` or `pk_test_`. |
| `config` | `FeedConfig` | **required** | Feed layout and behavior configuration. See [FeedConfig](#feedconfig) below. |
| `userId` | `String?` | `nil` | Known user ID. When provided, the SDK starts in identified mode immediately, skipping the anonymous-first flow. |
| `adProvider` | `ShortKitAdProvider?` | `nil` | Ad provider for monetization. Pass `nil` to disable ads. |
| `clientAppName` | `String?` | `nil` | App name included in analytics metadata. |
| `clientAppVersion` | `String?` | `nil` | App version included in analytics metadata. |
| `customDimensions` | `[String: String]?` | `nil` | Custom key-value pairs for analytics segmentation. Keys must be `"custom_1"` through `"custom_5"`. |
| `feedItems` | `[FeedInput]?` | `nil` | Content items to preload when using custom feed mode (`feedSource: .custom`). See [Custom feed input](/guides/content-types#custom-feed-input) for the shape. |

On initialization, the SDK pre-fetches the first feed page, pre-warms the CDN connection, and begins HLS preroll for the first video. The feed view controller can render immediately without a loading spinner.

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `feedHeight` | `FeedHeight` | `.fullscreen` | `.fullscreen` fills the entire screen. `.percentage(CGFloat)` sets a fraction of screen height (e.g. `0.85` for 85%). |
| `scrollAxis` | `ScrollAxis` | `.vertical` | `.vertical` for a standard up/down swipe feed. `.horizontal` for a left/right swipe feed. Each cell fills the feed container in both modes. |
| `videoOverlay` | `VideoOverlayMode` | `.none` | `.none` disables overlays. `.custom { ... }` provides a developer-built overlay managed by the SDK. See [Overlays](/sdk/overlays). |
| `carouselOverlay` | `CarouselOverlayMode` | `.none` | `.none` disables carousel UI. `.custom { ... }` provides a developer-built carousel overlay. See [Overlays](/sdk/overlays#carousel-survey-and-ad-overlay-modes). |
| `videoCarouselOverlay` | `VideoCarouselOverlayMode` | `.none` | `.none` shows only the SDK's native video pager with built-in page indicators. `.custom { ... }` provides a developer-built overlay rendered on top of the native video pager. See [Overlays](/sdk/overlays#video-carousel-overlays). |
| `surveyOverlay` | `SurveyOverlayMode` | `.none` | `.none` disables survey UI. `.custom { ... }` provides a developer-built survey overlay. See [Overlays](/sdk/overlays#carousel-survey-and-ad-overlay-modes). |
| `adOverlay` | `AdOverlayMode` | `.none` | `.none` disables native ad overlays. `.custom { ... }` provides a developer-built ad overlay. See [Overlays](/sdk/overlays#carousel-survey-and-ad-overlay-modes). Only applies to native ads; system-defined ads (IMA/VAST) are unaffected. |
| `muteOnStart` | `Bool` | `true` | Whether video starts muted. Once the user unmutes, the unmuted state persists for the session. |
| `autoplay` | `Bool` | `true` | Whether video starts playing automatically when the feed loads or when the user swipes to a new item. |
| `feedSource` | `FeedSource` | `.algorithmic` | `.algorithmic` fetches content from ShortKit's recommendation engine. `.custom` uses client-provided items (pass via `feedItems` on `ShortKit.init` or call `setFeedItems()` / `appendFeedItems()`). |
| `filter` | `FeedFilter?` | `nil` | Server-side content filter. When set, the SDK fetches only content matching the filter criteria. See [FeedFilter](#feedfilter) below. |
| `pullToRefreshEnabled` | `Bool` | `true` (`false` on Web) | Whether the user can pull down at the top of the feed to reload it from the first page. Web defaults to `false` because pull-down is a touch gesture desktop users rarely expect; set it to `true` to enable it. Not yet supported on React Native, where pull-to-refresh is always on. |

## `FeedFilter`

`FeedFilter` controls which content the SDK fetches from the server. When set on `FeedConfig`, all feed requests (initial load, pagination, and pull-to-refresh) automatically apply the filter. When `nil`, the full unfiltered feed is returned.

Different filter fields are combined with AND logic — content must match all specified fields. Tags use OR logic within the `tags` array — content matching any of the provided tags is included.

The exclusion fields (`excludeTags`, `excludeSections`, `excludeAuthors`, `excludeContentTypes`, `excludeMetadata`) remove content instead: content matching **any** exclusion is left out, even if it matches every other field. See [Excluding content](#excluding-content).

| Property | Type | Description |
|----------|------|-------------|
| `tags` | `[String]?` | Filter by content tags. OR semantics — content matching **any** of the provided tags is included. |
| `section` | `String?` | Exact match on content section. |
| `author` | `String?` | Exact match on content author. |
| `contentType` | `String?` | Filter by content type: `"video"`, `"carousel"`, or `"video_carousel"`. |
| `metadata` | `[String: [String]]?` | Filter by custom metadata. Each key takes a list of values; content matching any value for a key is included (OR), and every key must match (AND). |
| `excludeTags` | `[String]?` | Leave out content carrying **any** listed tag. |
| `excludeSections` | `[String]?` | Leave out content in any listed section. Exact match. |
| `excludeAuthors` | `[String]?` | Leave out content by any listed author. Exact match. |
| `excludeContentTypes` | `[String]?` | Leave out content of any listed type: `"video"`, `"carousel"`, or `"video_carousel"`. |
| `excludeMetadata` | `[String: [String]]?` | Leave out content whose custom metadata matches any listed value for a key. Content that doesn't have the key is never left out. |

### Excluding content

Use the exclusion fields to keep specific content out of a feed, for example a viewer's own posts, authors they've blocked, or content rated above an age limit. ShortKit removes excluded content server-side before it builds each page, so pagination and pull-to-refresh never return it.

- Content matching **any** exclusion is left out. Exclusions take priority over the other fields.
- Each exclusion matches the same way as its counterpart: `excludeTags` against content tags, `excludeSections`, `excludeAuthors`, and `excludeContentTypes` by exact match, and `excludeMetadata` against custom metadata values.
- Content that doesn't carry the field is never excluded. An item with no `authorId` metadata key stays in a feed that excludes `authorId: ["user_8f3a2c"]`.
- A filter that sets only exclusion fields doesn't change how your feed is ordered; excluded items are skipped. Leave the other fields unset rather than empty. An empty list counts as set, and setting any of them returns filtered results instead.
- Exclusions are sent with every feed request. Keep each list to a few hundred values.

To exclude a viewer's own posts, store the poster's ID in custom metadata when you upload each item (for example `customMetadata: {"authorId": "user_8f3a2c"}`), then exclude that key for the signed-in viewer.

### Filtering by language

ShortKit automatically detects the spoken language in every video and stores it as `customMetadata.language` using a [BCP 47](https://www.iana.org/assignments/language-subtag-registry/language-subtag-registry) code. Use this with `metadata` to serve a language-specific feed without any extra work on upload.

<Tabs>

    ```swift
    // Spanish-language feed
    let config = FeedConfig(
        filter: FeedFilter(metadata: ["language": ["es"]])
    )
    ```
  </Tab>
  <Tab title="Kotlin">
    ```kotlin
    // Spanish-language feed

        filter = FeedFilter(metadata = mapOf("language" to listOf("es")))
    )
    ```
  </Tab>
  <Tab title="Flutter">
    ```dart

      filter: FeedFilter(metadata: {'language': ['es']}),
    );
    ```
  </Tab>
  <Tab title="React Native">
    ```tsx
    // Spanish-language feed
    <ShortKitProvider
      apiKey="pk_live_..."
      config={{ filter: { metadata: { language: 'es' } } }}
    >
      <ShortKitFeed style={{ flex: 1 }} />
    </ShortKitProvider>
    ```
  </Tab>
  <Tab title="Web">

Common language codes: `"en"` English, `"es"` Spanish, `"fr"` French, `"de"` German, `"it"` Italian, `"pt"` Portuguese, `"ja"` Japanese, `"ko"` Korean, `"zh"` Chinese, `"ar"` Arabic, `"hi"` Hindi. `"und"` indicates no detectable speech (music or ambient audio). Language is set asynchronously — it appears on the content object within a few minutes of the video reaching `ready` status.
